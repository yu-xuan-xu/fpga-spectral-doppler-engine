# Fixed-point arithmetic contract

## General rules

- Input I/Q: signed Q1.15, saturated to `[-32768, 32767]`.
- Rounding: nearest; exact half cases move away from zero.
- Observable stage boundaries saturate; wraparound is forbidden.
- Signed FFT indices are `0..127,-128..-1` in raw output order.

## Wall filter

For each component:

```text
y[n] = sat18(x[n] - x[n-1] + round_away(63*y[n-1] / 64))
```

State is cleared by reset only and continues across legal frame boundaries.

## Window

```text
coef[n] = round(32767 * (0.5 - 0.5*cos(2*pi*n/255)))
out[n]  = sat16(round_away(filter[n] * coef[n] / 32768))
```

The implementation narrows the window output to signed 16 bits so it can feed the resource-shared FFT. This narrowing is part of the implemented M1 oracle and supersedes the earlier provisional 18-bit logical FFT-input description.

## FFT

- Radix-2 decimation in time with bit-reversed input storage.
- Q1.15 twiddles generated by `scripts/generate_fft_assets.py`.
- Every stage scales both butterfly outputs by two using ties-away rounding.
- Eight stages produce total normalization `1/256`.
- FFT storage and output are signed 16-bit; wrapper outputs are sign-extended to 18 bits.

## Power and result mapping

```text
power               = Re*Re + Im*Im        # exact unsigned 37-bit
frequency_q8_hz     = signed_bin * 20000
velocity_q8_mm_s    = signed_bin * 3080
```

The velocity host conversion is `velocity_q8_mm_s / 256000` m/s.

## Confidence rule

M1 uses a deterministic relative prominence rule. A result is low-confidence when the selected peak power is less than three times the greatest allowed non-peak bin power. Zero spectra are low-confidence. The fixed-point oracle and RTL compare powers without division.
